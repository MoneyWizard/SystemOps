SystemOps

v1.0.0 PowerShell Gallery GitHub GitLab

Lightweight memory diagnostics, dynamic working-set trimmer, and WSL2 host resource reclamation engine for Windows.

Install-Module -Name SystemOps -Scope CurrentUser

Live Diagnostics

Run Get-SystemVitals or shorthand vitals for instant CPU, physical memory commitment, and kernel cache loads.

Memory Reclaim

Run Invoke-MemoryReclaim or reclaim to sweep bloated working sets and drop dormant process caches safely.

WSL2 Reclamation

Integrates dynamic memory recovery targeting WSL2 virtual machine allocations when idle.

Built with PowerShell • Distributed via PSGallery, GitHub & GitLab
